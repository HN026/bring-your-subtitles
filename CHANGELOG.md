# Changelog

## 0.1.0 — 2026-11-09

First prototype for desktop Chrome and Firefox.

- Import local UTF-8 SRT and WebVTT files over a YouTube video.
- Adjust subtitle delay, text size and vertical position.
- Follow the video clock when seeking and changing playback speed.
- Hide captions during known YouTube ad states and clear them for a new video.
- Keep files in tab memory with no uploads, accounts or network requests.
- Include automated parser, launcher and controlled-player browser checks.

Live YouTube acceptance and browser-store signing remain outstanding. Direct subtitle-provider search is outside this release.
